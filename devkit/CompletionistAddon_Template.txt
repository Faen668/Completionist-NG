- ============================================================================
- COMPLETIONIST ADDON TRANSLATION FILE
- ============================================================================
- This file holds the text the player sees for CompletionistAddon_Template.ini.
- Give it the same name as your .ini, with .txt instead of .ini, and put it in
- Data\SKSE\Plugins\CompletionistData\Translations\
-
- EACH LINE IS:  the key, a TAB, a |, then the text.
-   - The gap after the key must be a TAB, not spaces. Several TABs are fine.
-   - The text runs from the | to the end of the line.
-   - Spaces at the end of the text are kept.
-   - Keys care about upper and lower case. Each key may appear only once.
-   - A missing key shows in game as the key itself, so it's easy to spot.
-   - Lines that start with - are notes, like this one. Blank lines are fine.
-   - Trailing : and spaces on headings and tab names are trimmed in the window.
-   - Save as UTF-8. Keep a - line at the very top of the file.
-
- TO TRANSLATE: copy this file and change only the text after each |.
- ============================================================================
