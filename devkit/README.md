# Completionist Dev Kit

Everything you need to give another mod its own page in Completionist: its items, books, places, quests and more. No code needed: an addon is two text files.

**[⬇ Download the Dev Kit (zip)](https://github.com/Faen668/Completionist-NG/raw/master/devkit/Completionist-Dev-Kit.zip)**

| File | What it is |
|---|---|
| [Completionist Addon Guide.md](Completionist%20Addon%20Guide.md) | The full guide: how addons work and every setting. |
| [CompletionistAddon_Template.ini](CompletionistAddon_Template.ini) | Every setting, with an example of each Type. Copy it to start your addon. |
| [CompletionistAddon_Template.txt](CompletionistAddon_Template.txt) | The translation file that goes with it. |

New to addons? The wiki walks you through your first one step by step: [Your First Addon](https://github.com/Faen668/Completionist-NG/wiki/Addon-Quick-Start). The whole Dev Kit section of the wiki starts at [Dev Kit](https://github.com/Faen668/Completionist-NG/wiki/Dev-Kit).

> Download the zip rather than copying the .txt from a web page: copying can turn its TABs into spaces, and Completionist needs the TABs.
